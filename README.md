# Nawyki 3.0

Tracker dobrych i złych nawyków na Androida.

## Funkcje
- ciemny / czarny interfejs
- dobre i złe nawyki
- sukces / porażka każdego dnia
- serie dni
- cele tygodniowe 1–7 dni
- procent skuteczności każdego nawyku
- statystyki 7 i 30 dni
- wykres trendu ostatnich 30 dni
- kalendarz i edycja wcześniejszych dni
- przypomnienia o wybranej godzinie
- eksport backupu do JSON
- przywracanie danych z backupu
- dane zapisują się lokalnie w telefonie

## Aktualizacja z 2.0
Aplikacja ma ten sam `applicationId`, więc instalacja APK 3.0 na wersję 2.0 powinna zachować dotychczasowe nawyki i historię. Stare nawyki dostają domyślny cel tygodniowy 7/7, który można zmienić przez **Edytuj**.

## APK bez Android Studio
Po wgraniu projektu do GitHuba workflow **Zbuduj APK** automatycznie buduje `app-debug.apk`. Gotowy plik znajdziesz w **Actions → udany build → Artifacts → Nawyki-APK**.
